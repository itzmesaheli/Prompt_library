# Versioned Marketing Prompt Library: Brewlane Coffee

A library of 5 reusable AI prompts for marketing workflows, with version numbers and a changelog.

## Prompts
1. Content Calendar (v1.2)
2. Ad Copy Variations (v1.1)
3. Email Newsletter (v1.1)
4. SEO Blog Outline (v1.0)
5. Customer FAQ (v1.0)

## Files
- prompt_library.json: prompt IDs, versions and variables
- Prompt_Library.pdf: full prompts and changelog

## How to use
1. Copy a prompt and replace the {variables}.
2. Run it in any AI assistant.
3. If the output misses the rules, edit the prompt, bump the version and add a changelog entry.

## Brand
Brewlane Coffee is a fictional specialty coffee subscription brand used for this project.
